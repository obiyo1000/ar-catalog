Analyzer Features

คุณสมบัติเด่นของเครื่อง

ออกแบบให้ทำงานรวดเร็ว ลดขั้นตอนการใช้งาน และช่วยควบคุมคุณภาพงานตรวจวิเคราะห์

Automatic Sampler
  • ดูดสารตัวอย่างเข้าเครื่องโดยอัตโนมัติ
  • รองรับ Syringe ชนิด Plastic และ Glass
  • ปรับมุม Sample probe ให้เหมาะกับการดูดสิ่งส่งตรวจ
  • มี Universal capillary sampling port ในแนวนอน
  • มี Integral adapter โดยไม่ต้องใช้ Adapter ภายนอก
Micro Sensor Card
  • ระบบตรวจวัดแบบ Micro Sensor Card Technology
  • ชุดตรวจวัดแยกอิสระจากน้ำยาตรวจวิเคราะห์
  • ตรวจวิเคราะห์ pH, pO2, pCO2, Hct, Na+, K+, iCa++, Cl-, Glu และ Lac
  • ทุกแผ่นมี RFID เพื่อบันทึกและวิเคราะห์ข้อมูลการใช้งาน
  • สามารถสร้าง Credit Code Warranty อัตโนมัติเมื่อใช้งานไม่ถึงเกณฑ์
RFID Management
  • ใช้ RFID กับน้ำยา Micro Sensor Card และน้ำยาควบคุมคุณภาพ
  • ไม่ต้อง Scan Barcode หรือป้อนข้อมูลด้วยมือ
  • บันทึก Lot Number และ Lot Expiration Date
  • แสดง Use Life Expiration Date / Time
  • แสดง Sample Remaining และ Use Life Percent Remaining
Flags & Status
  • มีระบบเตือนเมื่อตรวจพบ Flagging
  • แจ้งเตือนกรณีปริมาณสิ่งส่งตรวจไม่เพียงพอ
  • แจ้งเตือนเมื่อพบฟองอากาศในสิ่งส่งตรวจ
  • แสดงเวลาถอยหลังขณะวิเคราะห์หรือ Calibrate
  • แสดงสถานะ เช่น กำลังตรวจวิเคราะห์, Running QC, Calibrate

QC & Calibration

ระบบควบคุมคุณภาพและ Calibration

Quality Control
  • มีระบบ Automatic QC สามารถตั้งเวลาให้เครื่องทำ QC ได้เอง
  • น้ำยาควบคุมคุณภาพรองรับ 10 พารามิเตอร์ ได้แก่ pH, pCO2, pO2, Hct, Na+, K+, iCa++, Cl-, Glu, Lac
  • ชุดน้ำยาควบคุมคุณภาพ 1 กล่อง ประกอบด้วยน้ำยา 3 ถุง
  • แต่ละถุงมีปริมาตรต่ำสุด 100 ml
  • มีความเข้มข้นแตกต่างกัน 3 ระดับ
  • ชุดน้ำยามีอายุ 12 เดือนนับจากวันที่ผลิต
